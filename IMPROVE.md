Token efficiency matters, but never at the cost of a guess or of auditability: the cheapest *trustworthy and readable* form wins. Syntax stays familiar — Git hunk shape, SmPL-style `#` directives, Rust-shaped patterns — because agents and humans already know those spellings. ## Key decisions

- **D1. Losslessness is judged per origin corpus, in writing.** Native-origin diffs owe state-losslessness (post-tree byte-identical). Semantic-origin patches owe canonical losslessness for multi-site shapes and the defined fixed-point equality (`S″ == S′`, with WI-1 single-site instantiation equality) for single-site shapes. Raw native bytes never round-trip (0-context lowering, `index`/title stripping) — declared. Binary/gitlink/non-UTF-8/CRLF semantic compression stays out of scope; passthrough cycles must remain tree-lossless.
- **D2. No success field is true by construction, and no proof is a substring search.** Every `checked`/`verified` claim is computed by a check that can fail on real input at the reported span. Every `repair` is computed from the actual failure at the actual line. Round 9 extends the rule to raising itself: an emission claim (“this hunk is semantic”) is proved by re-applying the hunk, never by the detector's confidence (WI-1).
- **D3. Inference stays precision-first, and proof outranks bytes.** Every detector keeps pre-image totality (count equals pair count, zero opaque hits). Where the scratch-apply probe proves the exact site set, the WI-7 precision allowance (`semantic ≤ ordinary + 16 × claimed_sites + filter_block_bytes`, one formula in [guard.rs](/home/ai/git/tools/rsmpl-git/crates/rsmpl_diff_infer/src/semantic/guard.rs)) prices the emission; where no proof exists, strict T375 vetoes. A detector that cannot prove totality stays ordinary — no guessing.
- **D4. One anti-unification core, thin detectors.** Raising reuses [antiunify.rs](/home/ai/git/tools/rsmpl-git/crates/rsmpl_diff_infer/src/semantic/antiunify.rs) and the sub-line extractors instead of per-shape string surgery. Engine work is structural `syn` matching — concrete, fail-loud, no expansion, no guessing. Emission slices source spans verbatim; token re-rendering is a bug (WI-3), never a normalization.
- **D5. Split production code before growing; never exile tests.** New code lands in new modules; no item pushes a file over 2000 lines, a 1900-line warning gate fires first (WI-19), and any file over 1600 lines touched by an item leaves under 1600 or with its new code in a sibling module. Unit tests stay inline (`mod tests` at the bottom of the owning file); integration/e2e tests under `bin/*/tests/` and `crates/*/tests/` keep their names and stay exempt from the sibling rule by listing, not by silence (WI-20). Each work item keeps the smallest focused regression test with the project, inline in the owning file.
- **D6. Familiar syntax wins over clever syntax.** New surface reuses Git/SmPL/Rust spellings (`...`, `#` directives, concrete paths, `as` aliases, header pairs that look like the code they select). Diet remains canonical; the parser keeps accepting long forms so `.history/` archives stay readable. Any new spelling must be explainable in one AGENTS.md row. Round 9 adds no new directive keywords and no new CLI flags except WI-16's provenance verbosity flag, which only filters evidence the report already computes.
- **D7. Breaking changes are taken where they buy trust.** JSON schema stays at `version: 5` for additive keys; a key whose *meaning* changes bumps the version with the old key removed. SPEC text moves with code in the same item. Round 9 plans no version bump; WI-4's completed provenance and WI-16's summarized default are additive within v5 (the full log remains available unchanged under its flag).
- **D8. Anchors before indirection.** Follow, symbol resolution, and member anchoring prove site ownership from text the change already contains — fn-signature param types, `let` annotations, struct-literal paths, `use` chains, the enclosing `impl`/`trait` header, stated return types, one `Deref` step — before consulting any wider graph. A site no anchor proves is evidence (`orphans`/`follow_skipped` with a reason code), never a rewrite and never a veto on the proven sites.
- **D9. A rename owns its secondary definitions.** For every rename kind, SPEC enumerates the *definition set* (trait decl + impl definitions for associated items and trait methods; the binding + its scoped uses for locals; the `use` re-export tail for cross-file intents; the composed `impl` header for joint renames) and the follow/orphan machinery accounts for every member: rewritten, skipped with a reason, or the run degrades. WI-5 extends the set to renamed `let` bindings; WI-6 to the double-delta `impl` header.
- **D10. Auditability outranks byte-minimality.** When two emissions prove the same site set, `diffrs` emits the one whose pattern states its frame (holes + anchors), even at a small byte cost bounded by the WI-7 allowance. Bare-fragment emissions survive only where the fragment is the whole matched unit. A `- I` cut is never emitted as a *change representation* (cuts exist only paired with `# bind=`/`# use=` in moves, and only for items the engine can cite — WI-1). Bench claims follow the auditable form: benches `45`–`48` stay retitled as auditability intents until WI-8's diet re-pins them.
- **D11. Binder honesty is keyed by binding, not by spelling.** Any binder-adjacent work enters through the compiled pattern's binder identity, never a list of surface shapes. Body rewrites (the `as` splice, scoped body pairs, WI-5's scoped uses) are keyed by the *bound* occurrences of the renamed ident, never by word-bounded text; unclassifiable occurrences veto, they never ride a text scan.
- **D12. `partial` and `ordinary` must name their blockers — within a token budget.** A non-`verified` run states, per blocking rule, the counts that block it (orphans, follow-skips, ordinary hunks, unprobed shapes) in text and as JSON totals. An ordinary section names its top blockers by default and its full trial only on request (WI-16). “Somewhere in these 40 files” is not evidence; the agent's next action must be computable from the report alone, without paying 35 lines per hunk for it.
- **D13. Joints compose only under one probe.** A joint intent (rename+evolution, rename+addition/deletion, rename+body, rename+signature+body, move+delta, double-delta `impl`) is emitted only when a single scratch-apply of the *composed* emission against the pre-image reproduces the native plus lines at exactly the claimed sites plus every other line byte-identical. If any component delta fails the joint probe, the whole class stays ordinary. WI-14 spends this for the triple; WI-13 for two deltas sharing one line.
- **D14. Frames are raising context, never pattern syntax.** Frame unwrapping changes only which subterm the detectors see; emitted patterns never carry `fn`/`||`/`match` frame text, and authored patterns gain no frame spelling.
- **D15. Error guidance is keyed by layer, never copied across layers.** Parse-time failures teach marker discipline; engine-time failures teach content discipline (“paste `actual`”); build-time failures teach repair discipline. Each hint string has exactly one owning layer and one source string; documents quote it, never retype it (WI-9 generates the quotations, including the guard table).
- **D16. A splice that rewrites a body must prove the body.** Body-rewriting pastes and scoped body pairs prove, per occurrence, that the occurrence is the renamed item, and leave every other occurrence byte-verbatim or veto.
- **D17. Equality is site-set equality.** At N=1, two spellings are canonically equal iff instantiating each against the pre-image yields the same single site and the same post text at that site (proved by instantiation in [single_site_eq.rs](/home/ai/git/tools/rsmpl-git/crates/rsmpl_engine/src/single_site_eq.rs), never by normalizing pattern text). A template that would match a second site the literal misses is not equal, and its entry stays divergent with that reason named.
- **D18. Raising verifies itself (new).** `infer` reprobes every semantic emission against the pre-image map it already holds (the T361 byte-compare, section by section) and degrades any failing hunk to ordinary with `veto:reprobe-failed` before the patch leaves the library. `diffrs --check` remains the end-to-end verdict over the true post-tree; the reprobe is the per-hunk soundness floor beneath it. A detector with its own totality probe keeps it — the reprobe catches citation and pairing bugs (F1) that totality counting cannot see.
- **D19. History is a smoke test, not a gate (new; reverses round-8 WI-20).** The full-history sweep answers one question — *does the current tool still process the entire history without a conversion or re-apply failure* — and reports compression as information. There is no floor, no pinned window, and no pass/fail on how much compresses; a failure is a bug report with a commit hash, owned by WI-1's reprobe. Detector backlogs come from WI-4's counted provenance over recent ranges, run by hand, not from a gate artifact.
- **D20. Deferred means filed (new).** Any slice deferred by a landing commit is filed the same day as a numbered item in this plan or in [TASKS.md](/home/ai/git/tools/rsmpl-git/TASKS.md) with an owner — “filed as DISCOVERED” without a file is how F3's spacing bug and F8's diet spent a round unowned. Reviewers reject landing messages that defer to nowhere.
